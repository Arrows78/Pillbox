# Changelog

All notable changes to Pillbox are listed here, newest first. The file is generated by `scripts/release.py`
from the commit messages (Conventional Commits) and the `v*` tags: do not edit it by hand. See
`docs/RELEASING.md`. Versions follow [Semantic Versioning](https://semver.org).

## [0.5.0] - 2026-11-09

### Added

- **tabs**: Show the full name of the selected tab
- **prompter**: Prompter tab with a script list, speeds and voice following
- **calendar**: Calendar tab with today and tomorrow and a Join button
- **island**: Larger panel, header below the notch, hover tooltips
- **home**: Now playing and up next cards
- **prompter**: Click anywhere in the script to pause or resume
- **focus**: Block distracting apps, desktop name and camera islands
- **audio**: Per-app volume and mute in the Music tab
- **island**: Every tab opens at the terminal's height
- **capture**: Screen recording, screenshot annotation and QR code reading
- **battery**: Battery history chart, health, time remaining, fast drain and Bluetooth audio islands, network sparkline
- **home**: Use the taller panel on Home, Music and Timer
- **dictation**: Dictate into the front app from a global shortcut or the palette
- **activity**: Opt-in daily counter of clicks, keystrokes and mouse distance
- **timer**: One-click length presets as capsules
- **shelf**: Tile grid, add files button, item count and fuller context menu
- **clipboard**: Type filters, hover actions, empty states and island-style controls

### Fixed

- **tabs**: Keep the tab bar inside the panel
- **dictation**: Shorter permission island so it fits in every language

## [0.4.0] - 2026-11-08

### Added

- **ui**: Show the icon and version at the foot of the settings sidebar
- **settings**: Adaptive theme, startup, backup, shortcuts read from one source, fuller About page

### Fixed

- **build**: Keep macOS privacy permissions across updates
- Safe calculator in the palette, clipboard copies not skipped, pill width applied, single calendar timer

## [0.3.1] - 2026-11-08

### Fixed

- **build**: Export the signing identity in a format macOS can import

## [0.3.0] - 2026-11-07

### Added

- **ui**: Add a shared design kit and restyle the tab bar
- **ui**: Restyle the home, music and timer tabs
- **ui**: Rebuild settings around a sidebar and enrich the menu-bar menu

## [0.2.0] - 2026-11-07

### Added

- **music**: Add shuffle, repeat and an Apple Music favourite button
- **island**: Show download progress and builds, shake to open the shelf, add break reminders
- **palette**: Add calendar events and Apple Notes capture, show Bluetooth batteries
- **settings**: Choose the display, hide in full screen, add French strings, tests and docs
- **island**: Queue islands, add themes and click gestures on the pill
- **actions**: Add quick actions, web mini-apps and a notification island
- **a11y**: Label icon-only controls for VoiceOver and expose toggle state
- **l10n**: Add Spanish and German from a single checked table
- **settings**: Add theme, gesture and quick action settings, tests and docs
- **ai**: Warn before an AI usage limit is reached
- **github**: Add a pull requests tab through the gh CLI
- **hud**: Add an edge bar style for volume and brightness
- **l10n**: Translate the new texts in four languages and document them
- **mcp**: Add an MCP server and a Claude Code turn summary
- **player**: Add a floating player, full-screen lyrics, a copy stack and calculation history
- **island**: Resize the open panel and keep the terminal out of inherited directories
- **l10n**: Translate the new texts in four languages, add tests and docs

### Fixed

- **api**: Read the whole request body before routing
- **build**: Show compile errors and stop when the build fails
- **island**: Type-check the equalizer bar height with explicit types

## [0.1.0] - 2026-11-07

### Added
