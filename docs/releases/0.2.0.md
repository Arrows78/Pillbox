Pillbox 0.2.0 adds a lot around the island, the palette and AI tools, and fixes the local API.

### Highlights

- **For AI apps**: an MCP server (`Pillbox --mcp`) and a Claude Code turn summary, on top of the Allow / Deny approvals.
- **Pull requests** tab (through the GitHub CLI), and a **warning before an AI usage limit** is reached.
- **Floating player** in four sizes, **full-screen lyrics**, shuffle, repeat and an Apple Music favourite.
- **Several islands in a row** instead of one replacing the other, **themes**, **click gestures** on the pill and a **resizable panel**.
- **Quick actions and web mini-apps**, a **copy stack**, calculation history, and `event …` / `note …` in the palette.
- **Edge bar** for volume and brightness, download progress and build timer on the pill, shake a file to open the shelf.
- **Spanish and German**, next to English and French, plus VoiceOver labels.

### Fixed

- The local API could fail intermittently when a request arrived in several packets.

### Good to know

- The Spanish and German texts are machine translations that no native speaker has reviewed.
- Several features need a permission you grant yourself (Accessibility, Screen Recording, Full Disk Access, Input Monitoring); **Settings › Permissions** lists them.
